05 / Bachelor’s thesis

Urban Mail Rush

April—June 2025

An interactive 3D city-delivery simulation developed as my bachelor’s thesis. The system generates delivery points, optimizes their visiting order, builds routes through a road network, and guides the player along the active route.

Role Solo Unity developer
Type Bachelor’s thesis
Built with Unity · C# · Zenject · DOTween · Unity Test Framework

Routing & simulation

  • Generated delivery points and mapped them to the city road graph
  • Built initial routes with Nearest Neighbour and improved them with 2-opt
  • Used A* to find and cache paths between road-network nodes
  • Recalculated and visualized the active route with LineRenderer
  • Implemented player vehicle controls, NPC traffic, and obstacle handling
  • Added automated tests for the core routing algorithms

Performance testing: Nearest Neighbour completed in approximately 3 ms for 10 points, 12 ms for 20, and 25 ms for 30. The 2-opt pass took approximately 0.2 ms, and route visualization updates took approximately 2 ms.
