# Oleksandr Koshovyi — Unity Developer Portfolio

A static portfolio site built for GitHub Pages. It uses plain HTML, CSS, and
JavaScript, so no build step or package installation is required.

## Local preview

Run this command from the project directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish as a GitHub user site

1. Create a public repository named `criodash.github.io`.
2. Upload the contents of this directory to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.

The site will be published at `https://criodash.github.io`.
